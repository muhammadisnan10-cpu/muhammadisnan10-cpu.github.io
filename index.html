Pivot sales bulanan per regional dengan total nasional
Satu tabel ringkas yang langsung bisa dipakai untuk laporan target vs pencapaian.
CASE WHENROLLUPLEFT JOIN
 
-- Sales per regional per bulan, ditambah baris total nasional
SELECT COALESCE(p.region, 'NASIONAL') AS region,
       SUM(CASE WHEN s.period = '202401' THEN s.sales_total ELSE 0 END) AS sales_jan,
       SUM(CASE WHEN s.period = '202402' THEN s.sales_total ELSE 0 END) AS sales_feb,
       SUM(CASE WHEN s.period = '202403' THEN s.sales_total ELSE 0 END) AS sales_mar
       -- bulan berikutnya memakai pola yang sama
FROM dwh.project_dim p
LEFT JOIN dwh.cluster_sales_mart s ON s.cluster_id = p.cluster_id
GROUP BY ROLLUP (p.region);
Validasi data: bandingkan jumlah harian antara tabel olahan dan tabel sumber
Memastikan angka penjualan di laporan sama dengan data sumbernya sebelum dipakai.
Data validationGROUP BYTO_CHAR
 
-- 1) Seberapa baru data sumbernya?
SELECT MAX(order_date) FROM dwh.order_detail;

-- 2) Jumlah penjualan per hari di tabel hasil olahan (mart)
SELECT TO_CHAR(sale_date, 'YYYYMMDD') AS tgl, COUNT(1)
FROM dwh.sales_fact
WHERE period = '202411'
GROUP BY 1;

-- 3) Jumlah order per hari di tabel sumber, untuk dibandingkan dengan no. 2
SELECT TO_CHAR(order_date, 'YYYYMMDD') AS tgl, COUNT(1)
FROM dwh.order_detail
WHERE TO_CHAR(order_date, 'YYYYMM') = '202411'
GROUP BY 1;
Penjualan per cluster beserta atribut proyek
Menggabungkan transaksi penjualan dengan data proyek untuk dianalisis per wilayah dan jenis kemitraan.
LEFT JOININ / LIKEFilter multi-periode
 
-- Penjualan paket PL per cluster (Jan-Sep 2024) beserta atribut proyeknya
SELECT a.period, TO_CHAR(a.sale_date, 'YYYYMMDD') AS sale_date,
       a.service_id, a.package_name, a.channel,
       a.cluster_id, p.project_name, p.partnership_type,
       p.area, p.region, p.branch
FROM dwh.sales_fact a
LEFT JOIN dwh.project_dim p ON a.cluster_id = p.cluster_id
WHERE a.period IN ('202401', '202402', '202403', '202404', '202405',
                   '202406', '202407', '202408', '202409')
  AND a.sales_status LIKE '%SALES%'
  AND a.product_line = 'PL'
  AND p.partnership_type = 'Tipe A'
ORDER BY a.period;

Nama skema, tabel, dan kolom telah diganti dengan nama generik, dan sebagian kolom serta bulan dipangkas agar ringkas.
